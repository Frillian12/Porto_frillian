CCIS ICU

Critical Care Information System

A real-time monitoring system for a hospital ICU central nurse station — vital signs, ventilator settings, lab diagnostics and clinical severity scores on a single screen.

My role

  • Vitals — 24-hour multi-parameter trend charting
  • Diagnostic — lab results with reference ranges, ABG, microbiology and imaging panels
  • Clinical calculators — 11 validated scores: SOFA, SAPS II, APACHE II, qSOFA, SIRS, GCS, RASS, CAM-ICU, MEWS, PEWS, NEWS
  • Settings — ward-level alarm thresholds and parameter configuration

Impact

Scoring that ICU nurses normally do by hand — and skip when a ward is busy — became guided forms with saved history and automatic interpretation. Alarm limits moved out of hard-coded values into ward settings, so one system fits different units without a code change.

What I learned

Implementing a clinical score correctly means reading the source literature, not copying a table off the internet — SOFA traces back to Vincent et al., 1996. In a medical interface, colour and layout are safety features.

  • .NET Blazor
  • C#

  • Real-time

Qpro · Group project · .NET 9 + SQL Server

Hospital EMR

Electronic Medical Record for a private hospital

A new EMR replacing paper-based clinical documentation across inpatient and outpatient care. I built the clinical documentation side.

My role

  • SOAP notes and diagnosis coding
  • CMS — chief complaint, history of present illness, physical exam, review of systems
  • Allergies, problems and antibiotics
  • Physical examination forms, body diagram, patient information
  • Nursing assessment

Impact

These modules run on a template system rather than hard-coded pages, so the hospital can serve dozens of assessment forms — adult inpatient, paediatric outpatient, geriatric, obstetric, dental — through one interface. Clinical history that used to live on paper became searchable and reusable across episodes.

What I learned

Healthcare software is mostly data modelling, not screens. A "physical exam" is a different form for every specialty, so the real problem was a structure flexible enough to hold all of them without becoming unusable for the nurse filling it in.

  • .NET 9
  • C#
  • SQL Server
  • Template systems
  • Data modelling
